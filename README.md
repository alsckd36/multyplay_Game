# 🎮 Cyber Arena 2D - 실시간 멀티플레이어 서바이벌 대전

Node.js, Express, Socket.io 및 HTML5 Canvas로 제작된 실시간 2D 멀티플레이어 아레나 액션 게임입니다.

---

## ✨ 주요 기능

- 🌐 **실시간 양방향 통신**: Socket.io 기반의 초저지연 플레이어 동기화 및 60 FPS 틱 루프
- ⚡ **실시간 PvP 전투**: 마우스 조준 및 투사체 발사, 피격 및 넉다운 판정
- 💎 **파밍 & 성장 시스템**: 맵에 생성되는 보석(크리스탈)을 수집하여 레벨업, 기체 강화 및 HP 회복
- 💥 **시각 효과**: 화려한 네온 사이버펑크 테마, 피격 스파크 및 폭발 파티클 이펙트
- 🏆 **실시간 리더보드 & 미니맵**: 상위 10위 랭킹 및 전장 전체 플레이어 위치 추적
- 💬 **인게임 채팅**: 플레이어 간 실시간 텍스트 대화 지원
- 🔄 **부활 시스템**: 격추 시 점수 일부 보존 및 즉시 재출격 지원

## 🚀 빠른 시작 (로컬 실행)

### 1. 패키지 설치
```bash
npm install
```

### 2. 서버 실행
```bash
npm start
```
> 개발 모드(파일 수정 시 자동 재시작): `npm run dev`

### 3. 게임 접속 및 멀티플레이 테스트
- 브라우저를 열고 **`http://localhost:3000`** 에 접속합니다.
- **멀티플레이 테스트**: 브라우저 창(또는 시크릿 창)을 2개 이상 띄워 서로 다른 닉네임으로 접속하면 화면 간에 실시간으로 움직임과 미사일 발사가 동기화됩니다!
- **같은 와이파이(LAN) 기기 접속**: 내 PC의 로컬 IP(예: `http://192.168.0.x:3000`)로 스마트폰이나 다른 노트북에서 접속 가능합니다.

## 🕹️ 조작 방법

| 키 | 동작 |
| :--- | :--- |
| **W, A, S, D** 또는 **방향키** | 8방향 기체 이동 |
| **마우스 이동** | 조준 방향 회전 |
| **마우스 좌클릭** 또는 **스페이스바** | 에너지 투사체 발사 |
| **Enter** | 인게임 채팅창 열기 / 메시지 전송 |
| **ESC** | 채팅 입력 취소 |

## 👥 GitHub 협업 가이드 (팀원과 공동 개발하기)

### 1. 프로젝트 폴더 구조
```
multiplayer-game/
├── .gitignore          # Git 추적 제외 목록
├── package.json        # 프로젝트 정보 및 의존성
├── README.md           # 프로젝트 문서
├── server/             # [서버 파트]
│   ├── app.js          # Express 서버 및 소켓 이벤트 처리
│   └── gameLogic.js    # 충돌, 이동, 아이템 스폰 등 게임 물리 엔진
└── public/             # [클라이언트 파트]
    ├── index.html      # UI 구조 및 캔버스
    ├── style.css       # 네온 사이버펑크 스타일 시트
    └── js/
        ├── client.js   # 소켓 송수신 및 입력 처리
        ├── renderer.js # 캔버스 그리기 및 파티클
        └── ui.js       # HUD, 채팅, 모달 제어
```

### 2. 협업 추천 역할 분담
- **개발자 A (클라이언트/비주얼)**: `public/` 디렉터리 담당 (새로운 무기 이펙트, 스킨, 사운드 추가, UI 개선)
- **개발자 B (서버/게임엔진)**: `server/` 디렉터리 담당 (아이템 종류 다양화, 보스 몬스터, 맵 장애물 추가, 밸런스 패치)

### 3. 깃허브 브랜치 작업 흐름 (추천)
1. 기능 개발 시 새 브랜치를 만듭니다:
   ```bash
   git checkout -b feature/새기능이름
   ```
2. 작업 후 커밋하고 푸시합니다:
   ```bash
   git add .
   git commit -m "feat: 멋진 신규 기능 추가"
   git push origin feature/새기능이름
   ```
3. GitHub에서 **Pull Request (PR)**를 생성하여 팀원과 코드 리뷰 후 `main` 브랜치에 병합(Merge)합니다.

2. 생성된 주소(예: `https://your-game.onrender.com`)를 친구들에게 공유하면 전 세계 어디서든 함께 플레이할 수 있습니다!
